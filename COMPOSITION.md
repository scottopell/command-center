# Independent runtime functions

Build-time source composition is retired. Install an existing source folder through CommandCenter's Functions management UI. The public host contains only its system functions; it never searches for sibling repositories or includes private source implicitly.

See [function-pack authoring](FUNCTIONS.md), [runtime pack requirements](specs/function-packs/requirements.md), and [ADR-017](specs/adrs/017_runtime-packs-and-transition-diagnostics.md). Historical composition decisions remain in ADR-015.
